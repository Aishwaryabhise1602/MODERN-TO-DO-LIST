# Modern Todo List

A clean, responsive, and modern Todo List web application built with HTML5, Tailwind CSS, and Vanilla JavaScript with local storage persistence.

## Features
- Add, complete, and delete tasks
- Real-time remaining task counter
- Filter / clear completed tasks
- Persistent state via `localStorage`
- Responsive design styled with Tailwind CSS

## Deployment
This static website can be deployed to Vercel, GitHub Pages, Netlify, or any static host.
